## 🔍 What Is This Software?

lab-instrument-mcps is a collection of **MCP (Model Context Protocol) servers**. An MCP server is a small background program that acts as a bridge between an AI assistant (like ChatGPT or other AI tools) and your physical instruments.

Here's what makes this software special:

- **Real Instrument Control**: Connect AI agents to actual laboratory devices
- **Safety First**: Built-in safety limits prevent dangerous operations
- **Read-Only Mode**: Look at instrument data without making changes
- **Audit Trails**: Every action is logged and recorded for review
- **Built-In Simulators**: Practice with virtual instruments before connecting real ones

## ✨ Key Features

### 🛡️ Safety Limits
Every instrument connection comes with pre-configured safety boundaries. The software will refuse any command that exceeds these limits, protecting both your equipment and your data.

### 👀 Read-Only Mode
Not ready to let AI touch your instruments? No problem. Switch to read-only mode and the AI can only observe readings and monitor status — perfect for training and evaluation.

### 📝 Complete Audit Trails
Every single action taken by an AI agent is recorded. You can review exactly what the AI did, when it did it, and what the response was. This creates complete accountability and transparency.

### 🎮 Built-In Simulators
Each instrument type includes a realistic simulator. You can test everything without risking real equipment. Connect first to simulators, then switch to real instruments once you're confident.

### 🐍 Python Powered
Built entirely in Python, one of the most popular and flexible programming languages. This ensures wide compatibility and easy integration with scientific tools.

## ⚙️ How to Connect Your First Instrument

1. **Open the program** and click "Add New Instrument"
2. **Choose your instrument type** from the dropdown menu
3. **Select connection method** — USB, serial port, or network connection (your instrument's manual will tell you which one to use)
4. **Set safety limits** — the software asks about maximum values and restrictions. Leave the defaults if you're unsure.
5. **Click "Connect"** — the software establishes communication with your instrument
6. **Enable AI access** — once connected, click "Enable AI Control" to let AI agents interact with this instrument

## 🆘 Troubleshooting Tips

### Instrument Not Detected
Check that your instrument is powered on and properly connected via cable. Restart the application after connecting hardware.

### Connection Failures
Make sure the correct communication port is selected. Try the simulator first to confirm everything is set up correctly.

### Can't Enable AI Control
Verify you've set up all safety limits first. The software requires this configuration before AI access becomes available.

### Software Appears Frozen
Give it a moment — some instruments respond slowly. Watch the status bar for progress indicators.
